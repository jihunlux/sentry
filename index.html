센서 안내

SENTRY에서 활용하는 7가지 센서의 측정 대상과 활용 범위를 안내합니다.

℃

온도 센서

보관 공간의 온도 변화를 확인합니다. 시약별 허용 범위는 제품 라벨과 SDS를 기준으로 설정해야 합니다.

기본 구성 · 온도 모니터링
◌

습도 센서

보관 공간의 상대습도 변화를 확인합니다. 습기에 민감한 물질은 제품별 보관 기준을 별도로 확인합니다.

기본 구성 · 습도 모니터링
↻

용기 개폐 감지

용기 개폐 이벤트를 기록하는 개념입니다. 실제 기록은 센서 하드웨어가 연결되어야 가능합니다.

기본 구성 · 개폐 기록
◉

광센서

특정 파장의 빛이 물질을 통과하거나 흡수·반사되는 광학적 특성을 측정합니다. 빛에 민감한 시약의 광학적 변화 확인에 활용할 수 있지만, 분해 여부를 직접 확정할 수는 없습니다.

선택형 · 파장·측정 방식 검증 필요
pH

pH 센서

용액의 산성도와 염기성 정도를 측정합니다. 용액의 pH 변화 추적에 활용하며, 용액 종류와 측정 환경에 맞는 전극과 보정 조건이 필요합니다.

선택형 · 전극·측정 조건 확인 필요
◐

색상 센서

시약이나 용액의 색상 변화를 감지해 상태 변화의 보조 지표로 활용합니다. 조명과 주변 환경에 영향을 받으며 색 변화만으로 분해를 확정할 수 없습니다.

선택형 · 조명·색상 기준 보정 필요
☼

조도 센서

보관 공간 주변의 밝기와 빛 노출 정도를 확인합니다. 광센서가 물질과 특정 파장 빛의 광학적 상호작용을 분석하는 것과 달리, 조도 센서는 주변 환경 밝기를 측정합니다.

선택형 · 주변 밝기 모니터링
